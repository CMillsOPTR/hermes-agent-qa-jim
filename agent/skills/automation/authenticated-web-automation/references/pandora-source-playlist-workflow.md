# Pandora Source-Playlist Mutation Notes

For recurring playlist curation, use this verified interaction pattern:

1. Open the named source playlist first; do not infer the current page from the URL alone.
2. Confirm the source title and visible track list.
3. For each selected track, open its three-dot action menu and choose **Add to Playlist**, then select the persistent destination playlist (`Daily Recommendations`).
4. Avoid using the destination playlist's search/recommendation area when the source playlist workflow is available; it is easier to target the wrong object.
5. After the batch, navigate explicitly to `Daily Recommendations` and read back its title and item count. A count observed on the source playlist is not evidence about the destination.
6. Report success only from the destination read-back. If the destination shows one song, report one song even if the source contains twenty.

User-specific source weighting observed in this workflow:
- Motorcycle Music: favorite high-energy/phonk source.
- Carisma: broader variety.
- Vietnam Helicopter Raid: approved source.
- My Thumbs Up: broad fallback containing liked tracks.
- Target about 20 songs per day; exclude Christmas/holiday tracks unless requested.
